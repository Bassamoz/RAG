# ADR-002: عزل tenant/store

## الحالة
قرار تخطيط وفق المواصفات المطلوبة؛ التنفيذ غير متحقق.

## التاريخ
2026-11-06

## السياق
البحث PDF 53/56 يربط المستخدم بمتجر؛ المنتج يحتاج عضويات متعددة وعزلًا خارج SQL أيضًا.

## القرار
users/tenants/memberships/stores؛ اشتقاق scope من عضوية أو قناة موثقة. RLS وFK مركبة وtransaction-local ودور محدود؛ فهارس وcache/files/jobs مقيدة بالمتجر والإصدار.

## البدائل
فلتر ORM فقط يفشل مع raw queries والمهام؛ DB منفصلة لكل عميل مكلفة مبكرًا. service_role ليس مسار بيانات عام.

## النتائج والتحقق
اختبارات منع API/DB/pool/vector/cache/storage/export لمستأجرين وثلاثة متاجر في 02 ثم كل مرحلة. تكلفة التعقيد مقبولة لمنع التسرب.
