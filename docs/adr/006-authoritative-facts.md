# ADR-006: السعر والسياسة وحدود RAG

## الحالة
قرار تخطيط وفق المواصفات المطلوبة؛ التنفيذ غير متحقق.

## التاريخ
2026-11-06

## السياق
PDF 14–15 يستبعد المخزون الحي و17 يذكر APIs؛ السياسة والسعر قد يتغيران بعد الفهرسة.

## القرار
research يعتمد snapshot؛ production يعيد قراءة السعر/المخزون بأداة read-only موثقة. سياسة منشورة فعالة التاريخ مرجع الشروط. عند تعطل الأداة لا يؤكد سعرًا قديمًا؛ التعارض يستدعي توضيحًا/تحويلًا.

## البدائل
RAG وحده قد يسترجع سعرًا متقادمًا؛ نموذج يختار URL أو SQL حر يتجاوز التفويض. لا تعديل طلب أو مدفوعات.

## النتائج والتحقق
اختبار تغير variant/عملة/خصم وتعطل مزود وحذف سياسة أثناء query في 08/13. زمن وتكلفة الجلب تظهر منفصلة؛ صلاحية طلب خاص تحتاج تحقق عميل مستقل.
