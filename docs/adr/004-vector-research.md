# ADR-004: FAISS بحثي وpgvector تشغيلي

## الحالة
قرار تخطيط وفق المواصفات المطلوبة؛ التنفيذ غير متحقق.

## التاريخ
2026-11-06

## السياق
PDF 54–55 و84 يذكر FAISS منفصلًا عن قاعدة البيانات. المنتج يختار PostgreSQL.

## القرار
interface واحدة للمتجهات؛ pgvector تشغيل وFAISS بحث مع L2 normalized inner product. النموذج والأبعاد والإصدارات نفسها ضمن المقارنة، وتحقيق الصلاحية النهائي من DB.

## البدائل
pgvector وحده لا يعيد إنتاج FAISS؛ FAISS وحده ليس قاعدة معاملات أو بديل RLS. لا نظامي RAG منفصلين.

## النتائج والتحقق
اختبارات vectors معروفة وzero/dimension mismatch وعزل؛ Llama-3.1-8B-Instruct مرشح معلن لتجربة نفس النموذج مع/دون RAG. revision/ترخيص/موارد لم تثبت؛ لا إحلال صامت. 07/14.
